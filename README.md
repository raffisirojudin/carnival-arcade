## 📌 Tentang Carnival Arcade
  Carnival Arcade adalah sebuah wadah (*hub*) *mini-game* klasik berbasis browser yang mengusung tema karnaval atau pasar malam. Proyek ini dibuat sebagai bentuk nostalgia sekaligus latihan mengimplementasikan logika game (*game loop*) menggunakan JavaScript murni.

  ### ✨ Fitur Utama
  * **Game Collection:** Berisi beberapa game retro legendaris seperti Snake Game, Brick Breaker, dan Tic-Tac-Toe dalam satu aplikasi.
  * **Global Scoreboard:** Mencatat skor tertinggi (*high score*) pemain untuk memicu tantangan kompetitif.
  * **Vibrant Retro UI:** Antarmuka yang penuh warna dengan efek suara dan animasi khas mesin arcade zaman dulu.
  * **Keyboard & Touch Controls:** Game dapat dimainkan dengan nyaman menggunakan keyboard laptop maupun ketukan layar HP.

  ### 🛠️ Tech Stack
  * **Core:** JavaScript Game Loop, HTML5 Canvas, Audio Web API, CSS Grid untuk navigasi menu.
